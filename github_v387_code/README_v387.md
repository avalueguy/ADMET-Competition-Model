# v387 model code package

This directory contains the reproducible v387 expert code snapshot and the v387 submission CSV.

- `v387_model_code/`: frozen v387 scripts and source/data manifests.
- `v387_submission.csv`: v387 official-best submission associated with the user-reported score 51.314.
- `docs/`: v387 handoff, scorecard, diagnostics, and validation evidence.
- `SHA256SUMS.txt`: hashes for every package file.

The v387 training fits were performed on the designated remote host `connect.nmb2.seetacloud.com:25870`. The package does not contain credentials. The v387 result is experimental/reproducible evidence; it is not a guarantee of hidden-test performance.
