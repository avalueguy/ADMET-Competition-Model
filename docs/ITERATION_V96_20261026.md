# v96 化学身份标准化后的任务测量迁移

基线固定为用户官方最佳v94（50.916）。v95独立图模型同时进行；本分支与其独立，不根据v95确认结果选参数。

结构覆盖审查发现，中和最大母体后，其他任务测量在VDSS官方valid中的覆盖由27/113增加至72/113，溶解度由568/2940增至794/2940。该审查只使用分子结构及测量存在性，没有利用目标查询标签选择标准化规则。固定使用中和最大母体，不合并互变异构体。

原始精确身份的其他任务测量和mask保留为独立列，新增中和母体对应的测量、mask以及同一身份内的测量范围。整个目标任务从两种测量来源中剔除，目标标签不进入任何输入。盐形式与电荷可能真实影响测量，因此不直接把它们当作相同标签，不复制目标任务答案。

两种固定CatBoost专家：仅测量及基线rank、深度3；再加入435维描述符、深度5。直接与残差模式分别训练，两个固定种子964026/964027，1000棵树，100/300/1000检查点，学习率0.025、L2=25。分类Logloss、MAE任务直接优化MAE、Spearman任务高斯排名目标RMSE。CPU并行训练，图模型继续使用GPU。

fold0/1开发冻结每任务一个配置，最低门槛MAE相对下降1%、Spearman增加0.005、AUROC/AP增加0.002。冻结后计算fold2与valid，四部分全正且平均超过门槛才能提交；失败不更换候补。融合权重0.25/0.5/1。完整重放v94 HIA及历史已接受修正。

smoke已通过目标查询标签任意扰动后训练输入与目标不变、目标任务来源剔除、模型重载一致性。

不新增外部数据或预训练权重，只使用官方train/valid测量；测试结构来自模板，不打开test.csv。历史验证标签已反复复用，代理不是精确当前集成OOF，本地增益不能换算为官方分数。
