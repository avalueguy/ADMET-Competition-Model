# v100 三维结构核

在v98监督训练期间冻结并执行独立的GPU核路线，基线为v94（用户报告50.916）。目的为检查平滑相似性是否比树模型更有效利用新构象信息。

二维435维和三维1283维各自仅在目标任务fit分子上拟合中位数、标准差与有效列，缺失补中位数、标准差下限0.05、标准化后截断±6。每个视图使用按有效维数归一的欧氏距离，两种固定RBF带宽相加，再把二维/三维核等权相加。分别与六种指纹Tanimoto核相加或相乘。精确GPU Cholesky岭回归，alpha固定0.1/1/10，直接/历史残差两个目标。

协议`V100_PROTOCOL_20261026.json`在任何监督训练前保存。fold0/1选择唯一配置及0.25/0.5/1权重，门槛相对MAE1%、Spearman0.005、AUROC/AP0.002。冻结后fold2/valid确认，全四份收益为正且平均超过门槛才能接受；无候补。

最终v101按事前固定规则合并v95/v96/v98/v100通过的任务。同任务仅按开发fold0/1最小收益择一，平局选较低版本，不组合多个专家、不按确认结果调权重。没有新增外部数据和预训练权重，没有测试标签输入。

开发冻结7项，确认仅接受hERG和CYP2D6抑制任务。10份开发/确认/最终核缓存完成独立CPU双精度核预测、描述符fit时刻统计、目标查询标签扰动和线性方程抽样残差复核。最大CPU/GPU预测差约1.99e-5，线性方程抽样最大残差约5.44e-5。模板、来源、融合检查通过。

历史验证多次复用、代理并非精确当前集成OOF。本地收益不能换算官方涨幅，也不证明达到52。
