# v89：共享分子结构残差网络，开发失败

目标是检查多个任务共享学习历史基线误差，是否能提供超出单项条件修正的新信号。以 v88 候选为开发对照，最高已知官方版本仍为用户报告的 v86 **50.900**。

## 固定实验

输入为已核验的 12,288 维非负指纹特征的平方根及435维拟合行标准化理化描述符。不输入其他 assay 的实测值或缺失 mask，不新增外部数据或预训练权重。网络使用共享指纹/描述符编码、3个专家、分子及任务门控、零初始化残差输出。分类拟合固定校准基线 logit 上的 BCE；MAE拟合缩放残差的绝对误差；Spearman拟合 Gaussian-rank 残差。

每个外部查询骨架从所有任务训练标签中排除。两种子894026/894027，每个模型2400次按任务轮转的小批更新，检查点1200/2400，融合权重0.25/0.5/1.0。只用fold0/fold1选择；需两折同时达到相对MAE0.003、Spearman0.001、AUROC/AUPRC0.0005门槛，冻结后才可检查fold2/valid。

每任务实际仅约109次更新，且存在较强正则；这是一个有限的固定配置实验，不能据此否定充分训练的多任务表示。历史基线proxy不是完整当前版本同折OOF，标签已被历史使用；全局骨架排除比旧单任务基线更严格，两者训练条件差异如实保留。

## 结果

全部22任务均未达到两折同时改善门槛，冻结选择为空。没有进行fold2/valid确认训练，不生成最终模型或CSV，也不以确认集调参挽救实验。代表性两折增益：

| 任务 | fold0 | fold1 |
| --- | ---: | ---: |
| AMES AUROC | -0.004954 | -0.005800 |
| CYP2C9抑制 AUPRC | -0.000944 | -0.000417 |
| CYP2D6底物 AUPRC | -0.001452 | -0.045352 |
| PPBR相对MAE | -0.018571 | -0.014812 |
| 脂溶性相对MAE | 0.001557 | -0.007593 |

当前共享残差配置未能改善基线。不要将版本号当作已完成可提交模型；本轮可评测候选仍是v88，v86作为最高已知官方底稿。

## 保存与复核

保存4个开发训练模型各2个检查点，共8个权重。独立重建全部任务的全局骨架排除行、拟合行预处理、目标基线校准，验证权重和预测文件哈希、加载state后更换推理批大小并比较保存预测。复核范围见 `admet_model_outputs_v89/model_verification.json`。

拒绝分支增量归档依赖先恢复已核验的v86和v88归档；不包含测试标签、凭证。原始签名模型代码不可修改后复用缓存。官方分数没有新增结果，未自动提交平台、推送GitHub或关闭服务器。
