# v90：重新验证广覆盖分类残差的收益上限

用户报告 v88 官方分数 50.910，较 v86 增加 0.010；平台仍只显示总分。当前最优底稿为 v88，目标 52.0 尚差 1.090，最近用户提供的第十名为 52.7。

本轮对全部 13 个分类任务重新比较官方其他 assay 实测值及 mask、原始历史 rank-logit 的 CatBoost 残差模型，固定三种子 904026/904027/904028；配置深度/树数为 2/50、2/100、3/100、3/200、4/200；融合权重为 0.25、0.5、0.75、1.0。目标任务自身实测值和 mask 均排除。新分支无外部数据、新预训练权重和测试标签。

启动前修正未运行草稿：按模板声明 AUROC/AUPRC 评分，禁止根据类别比例猜测；开发、确认、最终均使用 sigmoid(mean(raw logits)) 三种子公式；残差从原始 v73 端点构造，当前 v88 仅融合一次；CYP3A4 底物的本地对照重放 v88 的已接受核模型。新缓存保存源码依赖签名、精确训练/查询行、来源、特征、校准和模型哈希，避免陈旧缓存混用。轻量 GPU 训练、CPU 重载及子批预测通过。

开发只看 fold0/fold1，最大化两折中较小的指标增益，且必须超过 0.0005。只冻结两项：CYP2C9 底物（d3/t200，权重0.5），CYP3A4 底物（d2/t50，权重0.5）。其余11项未过门槛。冻结后一次检查 fold2/official valid，四部分严格正增益才允许导出，不根据确认结果修改参数、权重或替补配置。

历史基线 proxy 不是完整 v88 精确 OOF；这些标签已在多轮历史实验中重复使用，fold2/valid 只是本轮未参与选参的确认集，并非全新独立数据。辅助其他 assay 来源允许同分子，因此属于条件预测诊断。不能从局部指标推算官方总分或承诺达到52。

确认结果：CYP2C9 底物 fold2 增加 0.017734，但 official valid 减少 0.024762；CYP3A4 底物 fold2 减少 0.004115，official valid 增加 0.003136。两项全部拒绝，无最终测试拟合、无 v90 CSV。共训练402个开发/确认模型（另有3棵树 smoke模型）。此固定配置路线不能支持大幅提分，但不代表所有模型已无提升空间。


独立重载402个模型，重建其他 assay 来源、精确训练/查询行、辅助值及 mask、校准、集成与子批预测全部通过。没有发现重载或来源实现错误；失败来自本轮固定候选在确认部分的不稳定收益。
