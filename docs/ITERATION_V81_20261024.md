# v81：多任务分类残差候选

v80 的官方成绩为 **50.647**，比 v73 的 50.640 提升 0.007。v81 以已验证的 v80 文件为锚点，重新筛选所有分类任务，寻找能把 v80 的单任务收益扩展到多个端点的方案。官方总分尚未获得，以下内部指标不能直接换算成平台分数。

本轮只选择三种子在旧 fold0、fold1、fold2 和官方 valid 全部不下降的任务：

- `bioavailability_ma`：AUROC，深度 3、100 棵树；
- `cyp2d6_veith`：AUPRC，深度 4、300 棵树；
- `pgp_broccatelli`：AUROC，深度 3、100 棵树。

每个任务使用 v80 相同的 offset residual 结构：把锚点预测转成 rank-logit，拟合正斜率 Logistic 校准，再用 CatBoost 学习分类残差。输入包括其他 21 个官方任务的 train+valid 实测值和缺失 mask，以及基线 rank-logit；目标任务值和目标 mask 从辅助输入中排除。最终使用三种子平均。没有读取测试标签，也没有使用外部数据。
