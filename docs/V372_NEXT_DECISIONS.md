# 五项 MAE 专家后续决策

五项各降10%是实验目标，不是可由算法名称保证的结果。v371未达到；v372结果以终态交付JSON为准。官方最好仍按用户反馈记录为v364=51.269。

下一轮优先修复评估依据，而不是继续扩大固定模型排列组合：

1. 重建当前每个MAE任务全部已采用组件的真实骨架OOF，替代历史代理对照；训练、特征预处理、专家融合和测量上下文规则均在相应拟合集内完成。保留当前冻结分区以便追踪，同时新增未来不反复调参的锁定评估集，不能把重复使用过的valid称作全新盲测。
2. 对Caco2/PPBR的重复测量按立体结构、盐型和来源做审查，量化条件差异，不能直接把不一致标签判为错误或删除。PPBR要比较原百分比MAE及边界覆盖，避免转换到logit后优化了错误目标。脂溶性要区分实验分配系数定义，溶解度要核实log尺度和测量条件，LD50要核实毒性单位与转换。
3. 用真实OOF残差训练带收缩的任务专属残差专家，评估结构域偏移和近邻覆盖；只在可由输入特征判断的区域启用，不能按未知测试误差逐样本挑模型。
4. 如仍采用Transformer，只在上述基线完成后，以同一分区和预算比较原尺度MAE/Huber、结构+指纹残差支路，及任务专属头；没有足够独立证据时不能声称它优于现有核/树集成。外部预训练权重或额外数据需先核对比赛规定，当前实验不使用。

目标收益的算术情景：若五个官方MAE确实都下降10%，其余17项固定，按历史成绩单复现的归一化公式总分约51.865。这个数字不是实验预测。当前可提交实验的官方效果必须由用户手动提交反馈确认。
