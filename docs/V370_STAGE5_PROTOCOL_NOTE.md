# 第五阶段：图 Transformer、分子指纹与 SAM

本轮基线为用户反馈官方分数 51.269 的 v364。所有 GPU 拟合均在用户指定的 `connect.nmb2.seetacloud.com:25870` 上完成。本地只打包数据、接收预测和核验结果。密码不进入项目文件。

实验覆盖 Caco2、LD50、脂溶性、PPBR、溶解度，每项独立拟合。既有六层原子/键图 Transformer 加入独立的 4096 维 count 指纹分支；数值描述符压缩至 64 维、指纹至 128 维，与图池化表示拼接后预测。现有指纹已是 count 类表示，只做拟合集 RMS 缩放及固定裁剪，不再次取对数或二值化。共 3,964,189 个参数。

对比两个固定训练方案：自监督初始化后 AdamW，和同一初始化后 SAM（rho=.05）配合 AdamW。两个方案使用相同双种子、数据、架构与更新步数；SAM 每次更新多一次梯度计算，所以计算量并不相同。SAM 两次前向使用同一批样本和同一 dropout 随机状态。最终预测统一用原尺度 L1 目标，拟合集 median/IQR 只用于仿射缩放。PPBR 固定输出限制 [0,100]；LD50 不额外变换标签。

每个分区独立预训练编码器，排除本轮五项全部查询骨架及 canonical structure。只复用确定性的图缓存，不复用此前阶段已学习的权重。不使用外部数据或外部预训练权重。对照重放 v364 已采用层：PPBR 的 v304 45%，脂溶性和溶解度的历史层及 v364 图预测 20%；final 对照逐项等于 v364 CSV。

有限候选为两个模式、20% 或 45% 数值融合及不采用。只用 fold0/1 选 max-min 唯一配方后冻结，再用 fold2 和 valid 确认；失败时不换配方。实验 CSV 至少要求四分区正增益；严格采用还要求实际增益门槛和两个骨架 bootstrap90 下界为正。不符合条件时不制造新 CSV。

历史完整集成的部分 OOF 是代理对照，公开验证标签长期复用。新的骨架隔离和 bootstrap 不会产生全新独立数据，四分区改善也不保证官方隐藏集改善。当前实验仅检验联合模型是否有新增信号，不承诺达到 52。

按照官方计分关系，若其余 17 项固定，五项 MAE 都相对下降约 12.13% 才能从 51.269 达到 52；五项都下降 5% 对应条件总分约 51.560。它们是条件算术，不是模型预测或成功概率。

冻结来源、完整参数和签名见 `experiments/transformer_stage5_v370/outputs/protocol.json`；进度见 `docs/v370_stage5_progress.json`。最终结论由训练结束后的结果报告给出。
