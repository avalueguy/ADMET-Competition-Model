每项独立选择专家，不继续批量扩展分类或Spearman任务。比较七个事先声明候选：

1. 六种count指纹、多尺度核及目标排除上下文组成的精确中位数核模型，两个正则惩罚C=3/30。
2. 直接原尺度分位数树，深度3/6，GPU XGBoost中位数目标，双固定种子。
3. 小型理化分位数线性先验加残差分位数树，深度3/6，先验仅拟合集估计。物理分支只是特征先验，不声称强制物理定律。
4. 三折拟合集内部骨架交叉验证产生参考模型残差，再按查询局部相似性作缩减中位数校正。历史集成预测不作为训练输入，不能拿拟合集重代入误差当OOF残差。

任务训练预算不同：Caco2=650、LD50=1100、脂溶性=1100、PPBR=900、溶解度=1400棵树/种子。该有限比较检验一条有针对性的专家更新路线，不宣称所有模型或参数都已穷举。部分方法族过去已有实验，此次新组合仍需新增证据。

仅用fold0/1选各项最差折增益最大的唯一模型和融合权重。固定比较20%、45%、75%、100%，包含不采用；开发不改善则停止该任务。之后冻结，再看fold2和valid，不因确认失败更换配方。严格采用仍要求四处正、原1.2%门槛及两份500次成组bootstrap90下界为正。已获授权的实验CSV可采用四处均正而严格稳定性不足的任务，必须标注，不能称目标完成。
