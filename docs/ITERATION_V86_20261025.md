更新：用户随后报告 v86 官方分数 **50.900**，较 v85 增加 0.011。以下保留生成时实验记录。

用户报告 v85 官方分数 **50.889**，相较 v84 增加 0.009，距离 52.0 仍差 1.111。v86 以 v85 CSV 为固定底稿。v86 尚未获得官方分数。

## 实验与发现

对全部 13 个 AUROC/AUPRC 分类任务比较 XGBoost Logloss、MAP 排序、Pairwise 排序。输入分别为其他官方 assay 的实测值及缺失 mask、基线 rank-logit（aux），或额外加入理化描述符（compact）。固定两种子、200/400 轮、不使用查询标签早停。先在 legacy fold0/fold1 选择配置和 0.25/0.5/1.0 秩融合权重，要求两折最小收益超过 0.0005；冻结后仅一次检查 fold2 和 official valid，四部分均为正才采用。

检查已保存的树时发现，排序损失沿用了 Logloss 的 `min_child_weight=10`、L1=0.1、L2=50。完整审计确认 MAP 104 个、Pairwise 104 个模型全部零分裂，不能据此认为排序方向无效。该结果如实保留，不在原签名目录修改参数。后续 v87 使用适合排序梯度尺度的参数，独立保存源码、协议和模型。v86 最终采用的是正常产生分裂的 Logloss 模型。完整审计在 v86 归档之后单独生成于 `admet_model_outputs_v86/objective_scale_audit.json`，不在原归档 manifest 中。

## 冻结确认

3 个任务达到开发门槛；CYP2C9 底物 fold2 AUPRC 下降 0.010066，CYP3A4 底物 fold2 AUROC 下降 0.002140，均拒绝。只有 CYP2D6 底物通过：

| 部分 | v85 重放基线 AUPRC | v86 AUPRC | 增益 |
| --- | ---: | ---: | ---: |
| fold0 | 0.573465 | 0.585376 | 0.011911 |
| fold1 | 0.631228 | 0.643623 | 0.012396 |
| fold2 | 0.650830 | 0.653778 | 0.002948 |
| official valid | 0.722158 | 0.723739 | 0.001581 |

配置为 aux、Logloss、深度 3、200 轮，固定种子 864026/864027。每成员预测包含固定校准 base margin，先平均 raw margin 再 sigmoid；最终与 v85 按秩 25% 新专家、75% 底稿融合。最终更新 CYP2D6 底物 **135 行**，其余 21 任务的预测字符串逐字保留。模型最终拟合使用官方 train+valid，测试结构仅来自模板。

## 复核与不确定性

独立进程重载 10 个 booster（四个开发/确认部分及最终部分各两种子），检查文件哈希、源行、目标 assay 排除、canonical/scaffold 分离、辅助值逐项重建、rank-logit 校准、base margin、输入设计、树数、目标函数、整批/子批预测、成员均值和最终 CSV。官方模板的 drug_id 原始字符串、行序和其他字段不变，逆向替换 y_pred 后字节完全复原模板，包括 BOM/CRLF。

配对骨架 bootstrap 各 1,500 次，仅报告、不修改冻结选择：

| 部分 | 增益 95% 区间 | 正增益比例 |
| --- | --- | ---: |
| fold2 | [-0.009094, 0.025016] | 72.93% |
| official valid | [-0.018793, 0.027898] | 47.33% |

两区间均跨零，valid 证据尤其偏弱。历史基线 proxy 不是完整 v85 的精确同折 OOF，开发及确认标签已长期复用。同分子其他任务实测值属于条件预测信息；目标任务标签与 mask 已排除。没有新增外部数据或预训练权重，历史底稿包含早期预训练来源。局部指标不能换算为官方总分，也不足以证明能达到 52。
