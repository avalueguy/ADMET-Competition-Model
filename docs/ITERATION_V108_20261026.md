# v108：官方数据监督表示学习与独立任务微调

官方最佳仍为 v101，用户报告 50.932。v107 官方 50.909，已撤回推荐。

## 原因与本轮改动

v107 的最终文件可从模型缓存逐值重建，格式正确；退分不能归因于上传格式。其 hERG 验证集只有 66 行，增益的分组 bootstrap 区间跨越 0。多轮复用验证标签，加上不完整的历史代理基线，使小增益的可信度有限。

v108 改为两阶段训练：在官方训练数据上学习分子表示，再分别微调每个任务的编码器和预测头。使用六组分子指纹及理化描述符，不把其他任务实测值作为输入，不下载外部数据或预训练权重。每个任务同时训练相同结构的从零训练对照。

训练包括两个随机种子，监督阶段 2,200 步，任务微调 1,000 步；固定对末段权重求平均，不搜索多个检查点。分类、排序和绝对误差任务使用相应目标。新模型与 v101 的融合权重预先固定为 35%。

## 验证约束

- legacy fold0/1 仅用于确定任务名单；每项改动既要超过历史代理，也要显示迁移相对于同结构从零训练的收益。
- 名单冻结后检查 fold2、官方 valid；随后使用新划分的分子随机和骨架留出集核查迁移效果。
- 使用分组 bootstrap 检查合并公开验证预测的增益区间，不把区间解释为官方分数区间。该区间没有校正筛选效应。
- 未通过约定条件的任务不换备选参数。没有通过候选时不生成换名的旧提交。
- 查询标签扰动、CPU 独立前向重建、模型哈希及模板非预测字节检查必须通过。

完整、可机器检查的参数及门槛以 `admet_model_outputs_v108/protocol.json` 为准。

## 局限

历史 v101 的验证数组可以复算，但其完整旧模型无法全部在服务器上重新训练，因此不能把它称为完整同折重训基线。同结构从零训练对照用于检查本次迁移策略；相对于 v101 的比较仍须标明历史代理的限制。

重新划分公开标签不能产生新的独立数据。所有本地收益均不能换算成平台积分，也不能保证达到 52 分。当前无 v108 官方成绩。

本轮不自动提交比赛、不 push GitHub、不关闭服务器。任何提交 CSV 仅更新 y_pred，保留模板 Drug_ID 字符串、顺序、BOM、CRLF 及其他全部字节。
