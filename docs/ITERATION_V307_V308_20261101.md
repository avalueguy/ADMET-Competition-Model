# v307 / v308：联合优化的可微分树

香港时间：2026-11-01。官方最佳 v145，51.166；目标 52，尚未达到。

## 冻结方案

五个 MAE 任务，各 64 棵深度 5 的可微分 oblivious 树。每个树层以 entmax1.5 学习稀疏特征选择，sigmoid 计算左右分支概率；特征选择、阈值、温度和叶值在同一个 MAE 目标下联合优化。两种子固定，训练更新数仅由拟合行数和预定公式决定，树输出有 10% dropout。

输入为官方归档的 512 个拟合方差筛选指纹列、理化/形状特征与排除当前目标的测量上下文。经验分位变换、缺失指示、目标尺度以及阈值初始化均只用当前拟合集。无外部数据、预训练参数、历史预测输入或检索目标标签。

历史检查未发现该联合优化机制。v216 是贪心 CatBoost，v278 固定实际 v145 树结构后仅重估叶值；v301 是共享权重 MLP，v304 学习参考标签注意力。本轮没有复用这些被拒绝专家的预测。
