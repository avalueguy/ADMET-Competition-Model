# v74 实验记录

本轮以用户报告 50.640 的 v73 CSV 为锚点，训练任务专属 MAE 神经专家，目标为寻找与历史集成互补的、可复算的新分支。新增分支只使用官方结构与 train/valid 标签，未使用外部数据或预训练权重；继承锚点保留历史预训练来源。

## 验证设计

1. 保留 v67 的三个全局骨架分组，train 内 fold0/1 只用于选择方法。
2. 每个外层拟合集的 15% 骨架组作为内部停止集，停止轮数由内部标签确定。预处理只在相应拟合行上计算。
3. 在外层允许的全部拟合行上重新训练。图、指纹、混合头使用各自的内部停止轮数。
4. CatBoost MAE 对照使用相同的外层拟合行/查询行，也先在内部确定树数后重训。
5. 只在 fold0/1 选专家头与 0 或 0.5 的树融合。与锚点融合的权重预先固定为 0.5。
6. 选择文件写出后，才训练 fold2 和官方 valid 的确认预测；确认采用与最终提交相同的三个随机种子平均。只作通过/拒绝判断，不根据确认标签重新选择头、权重或轮数。
7. 通过后用 train+valid 重训三个种子；轮数采用四个开发部分内部停止轮数的逐头中位数。独立进程重载全部开发及最终模型，复算融合。

完整 v73 历史集成权重不足，无法计算任意新折的精确 v73 OOF。历史数组仍是不同折叠/部分不同集成身份的代理；其结果仅作明确标注的补充筛选，不作为严格同条件整集成提升证据。所有开发标签此前被反复使用，因此确认集也不是全新独立测试。官方得分必须等待平台。

## 已修正的实现问题

首个尝试把各头内部最佳轮数取中位数用于全部头重训，图头与指纹头收敛速度不同，导致部分头训练不足。该尝试已中止并留在独立 attempt1 目录。活动 v74 改为逐头轮数，并在空输出目录从头重跑，未复用失效签名缓存。

## 复现入口

- `admet_v74_protocol.json`：冻结训练协议
- `admet_v74_specialists.py`：官方分子图缓存、内部停止、外层重训、树对照
- `tools/select_v74.py`：前两折选择和后续确认（两个阶段）
- `tools/run_v74_confirmation.py`：先冻结，再训练确认三种子
- `tools/finalize_v74.py`：最终训练与模板导出
- `tools/verify_v74_models.py`：独立重载及融合/模板复算
- `tools/package_v74_release.py`：活动实验权重归档及逐成员校验

本轮在远程 A100 40GB 训练；未自动上传比赛、push GitHub 或关闭服务器。

## 前两折冻结选择

- 脂溶性：混合神经头与树各半；相对同训练行树对照，fold0/1 的 MAE 分别降低约 7.80% / 5.53%。
- 溶解度：三个神经头平均与树各半；虽然单独神经模型偏弱，融合仍显示互补，fold0/1 降低约 1.37% / 3.08%。
- PPBR：混合神经头与树各半；fold0/1 降低约 5.12% / 4.99%。
- Caco-2 与 LD50 未通过预设选择条件，不进入确认。

上述为同条件新树对照的开发相对误差变化，不是相对完整 v73 的独立结果，更不是官方分数变化。

## 冻结后的确认结果

只有 PPBR 通过了确认条件，最终以三种子混合神经头与树模型各半形成专家，再与 v73 的 PPBR 预测各半融合。

| 确认部分 | 样本数 | 同训练行树 MAE | 新专家 MAE | 相对树降低 | 历史代理 MAE | 半权重融合代理 MAE |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| train 内 fold2 | 651 | 7.838890 | 7.255082 | 7.45% | 7.106893 | 7.017845 |
| 官方 valid | 279 | 11.174572 | 9.968810 | 10.79% | 9.722893 | 9.678300 |

融合后的代理 MAE 分别降低约 1.25% 和 0.46%。代理不是精确的同折 v73 全集成，因此这些数字不能视作相对 v73 的独立收益估计，也不能换算为官方总分。

脂溶性的新专家超过同训练行树，但固定融合在官方 valid 上使历史代理 MAE 变差约 1.95%，按原定规则拒绝。溶解度在官方 valid 上没有超过树，且融合使代理变差约 2.21%，也拒绝。Caco-2、LD50 在选择阶段已被拒绝。未根据确认标签改权重或放宽规则。

本轮尝试了新的图模型分支，但最终只有一个任务获得足够的本地支持。它可以检验 PPBR 是否提供线上互补，尚不能证明已经找到填补 1.060 分差距的整体路线。

## 模型及文件检查

远程独立进程重载了 174 个神经/树模型，其中最终模型 10 个。训练/查询行身份、骨架排除、预处理、批大小不变性、冻结选择与确认门控、融合重算均通过。CSV 包含 16,379 行、22 个任务、6 列；只改 PPBR 的 559 条预测，官网模板的所有非预测字节完全一致，包括 `.0` 药物 ID、BOM 与 CRLF。

候选 SHA256：`ff1d2f14f5d5f4a9518f4998e2d15323401c2a78d9a4559552eb2d1c7e3b3321`。

新增分支权重、官方输入、特征、冻结记录、源码和日志共 477 个归档成员，远程逐成员 SHA256 检查通过。该归档不声称包含完整历史锚点的全部权重。本地下载后的独立归档和融合核验结果见 `docs/v74_delivery.json`；本地交付脚本为 `tools/finalize_v74_delivery.py`，仅用 NumPy 和标准库，不执行训练。
