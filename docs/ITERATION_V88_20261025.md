# v88：跨任务指标的平滑交互核

用户报告 v86 官方分数 **50.900**，较 v85 增加 0.011，距离目标 52.0 还差 1.100。v88 以 v86 提交文件为固定底稿，尚无官方成绩。

## 方向与协议

上一轮直接排序在开发折的大幅收益未通过确认。本轮对全部 22 项比较三种平滑残差核：其他官方实测指标及其缺失 mask 的 RBF 核（measured）；其与化学邻居其他 assay 汇总核的均值（phenotype）；该核与分子指纹/理化结构核的乘积交互（product）。每种 3 个正则强度，3 个融合权重。目标任务实测值、mask 和全部 5 个目标 assay 邻居字段排除。landmarks 只从拟合行 canonical 去重分子抽取至多 384 个；所有预处理、校准、目标变换和系数均只用拟合行。

开发只使用 legacy fold0/fold1，按最小增益选一个配置和融合权重，门槛为相对 MAE 0.003、Spearman 0.001、AUROC/AUPRC 0.0005。冻结 7 项后仅一次确认 fold2/official valid，四部分增益严格正才采用，不根据确认结果改参数、权重或替补配置。

## 复核及限制

独立重建其他 assay 来源与实测值、邻居 profile 的 source/ref/label，检查目标 assay 排除、精确训练查询行和骨架/canonical 分离、拟合行预处理与landmarks、CPU float64 核设计复算。5 个模型（4个开发/确认+最终）保存系数重载与重新拟合一致，整批/子批推理和最终融合一致。复用 profile 的来源和选定查询点邻居汇总也经独立 CPU 复算。模板非预测字节完全保留，包括 drug_id 原始字符串、BOM 和 CRLF。

配对骨架 bootstrap 每部分 1,500 次，仅报告不改变选择：fold2 增益95%区间 [-0.004046, 0.010625]、正增益比例85.40%；valid区间 [-0.009788, 0.018237]、正增益比例55.73%。区间均跨零，证据支持小幅候选尝试，不能承诺线上涨分或达到52。
