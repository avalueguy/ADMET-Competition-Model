# 第三阶段：扩展四项图 Transformer 专家

2026-11-05（香港时间）。用户指定本轮及后续训练改用 `connect.nmb2.seetacloud.com:25870`，覆盖此前 24365 端口约束。密码只通过交互认证使用，不写入项目文件。

当前有官方反馈的最好版本仍为 v364，51.269。v366 的 LD50 实验尚无官方反馈，本轮直接以 v364 为对照，避免叠加尚未确认的修改。

本轮任务为 AMES、微粒体清除率、半衰期和 VDss。这四项尚未运行前两阶段的原子/键图 Transformer。它们分别检验毒性家族迁移与药代动力学家族迁移能否带来新的互补预测。架构沿用已核验的六层、192 维、六头图 Transformer；不将复用架构本身描述为新算法成果。

三条固定消融：从零训练、自监督预训练、相关任务迁移。每条使用两个固定种子。AMES 解冻末两层及适配器，使用 BCE 加成对排序；三项 Spearman 任务冻结主干、训练 rank8 适配器，使用拟合集 Gaussian-rank 变换、平方误差及成对排序。

所有 GPU 训练在用户新指定的 RTX 3090 24GB 上进行，环境与前轮匹配。自监督编码器按分区重新训练，排除四项查询骨架并检查规范结构不重叠；只使用官方拟合数据，不引入外部数据或外部权重。测试标签为 NaN，不能参与拟合、归一化或选择。

开发阶段仅使用 fold0/1，选择最大化最差分区增量的唯一模式和融合权重（0、20%、45%）。冻结后才运行 fold2 和公开 valid。严格规则保持原有门槛；已获授权的实验候选要求四分区全部正向，但置信区间不足时必须明确标注。确认失败不改权重补选，未通过任务保留 v364 输出。

本轮控制预测的最终输出与 v364 CSV 完全一致。历史完整集成 OOF 仍有代理成分；公开 valid 标签已长期复用。AMES valid 在现存分组中只有一个组，不能建立骨架 bootstrap 置信区间；半衰期 valid 的组间隔离拟合集仅 160 行。这些限制不能通过更多训练抹去。

本轮四项中只有 AMES 为 AUROC，其余为 Spearman。若 AMES AUROC 增加 0.02、三项 Spearman 各增加 0.10，按现有计分关系，条件总分也只增加约 0.222，到 51.492；这只是算术情景，不是预测。大幅总分增长需要多项任务出现更强且可泛化的增量，不能把训练损失下降当作官方提分。

输入证据：`v368_input_package.json`、`v368_input_audit.json`。训练状态：`v368_stage3_progress.json`。最终应交付逐字节核验的 CSV、分项结果、失败记录和恢复所需的模型检查点。
