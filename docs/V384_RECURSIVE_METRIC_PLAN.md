# v384：以完整 v382 为基线的任务自适应核

用户确认 v382 官方 51.299。新实验以原始 v382 全部 22 项输出为基线，两个更新任务的 fold0/1/2、valid、final 控制均由原来源重建。v383 仅单独恢复旧脂溶性，无新增训练，其条件算术约 51.300112，不是官方分。

检索本地 tools 源码未发现 recursive feature metric / RFM / gradient outer product 同机制实现。已有核、树、Transformer、检索、内层 OOF 融合都保留原结果，不重复宣称新方法。这一轮只测试一个明确机制：用各任务训练标签学习分子表示中不同坐标的重要程度。

6 组计数指纹分别恢复计数、归一化开方，每组仅依训练特征方差选 128 维，合计 768 维；上下文以训练集稳健尺度处理选 256 维。分块归一化后构建 Laplace 距离核。epsilon=0 的 SVR 优化原标签尺度的 MAE 目标，以模型在训练点的输入梯度平方均值更新对角度量；更新有 0.5 阻尼、0.2 均匀收缩和有界权重。它借鉴递归特征度量思路，是独立的对角 SVR 变体，不冒称论文标准实现。

固定 C=3/30。每条曲线完整拟合轮次 0 至 8，每次优化到 tol=1e-5 或明确记录失败；保留轮次 0/2/5/8。轮次 0 是固定几何的消融。全部 9 项、2 个开发分区、2 个 C、9 次求解，共 324 次开发拟合；不会因前期不好中止。只有全部完成后才选型。

沿用可审计的 max-min fold0/1 单一配置和融合权重选择。冻结后检查 fold2 与公开 valid，不在确认失败后换第二候选。实验提交需四分区 MAE 全部改善；四个 Spearman 任务还需四分区排序指标全部改善。严格稳定性另需既有实用阈值和分组 bootstrap 区间，不能把未达严格门槛说成稳定提升。

所有拟合和 GPU 矩阵运算在指定远端进行。本地只组装输入、登记结果、核验和保存提交文件。查询标签扰动、模型独立重放、哈希、分组隔离和官方模板检查必须通过。只使用已有官方数据。旧模型控制部分为历史 proxy，四排序任务 MAE 为校准参考，公开验证多次复用，因此不能称盲测或预报官方必涨。
