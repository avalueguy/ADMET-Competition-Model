## 本轮比较

在 22 项任务上比较三类残差模型：指纹广义 Tanimoto Nyström 核、理化描述符 RBF Nyström 核、其他官方 assay 的线性残差修正。每类固定 3 个正则强度，再比较 0.25、0.5、1.0 三种修正强度，共 27 个配置。核模型只从拟合行抽取至多 384 个去重 canonical 分子作为 landmarks；描述符预处理、目标变换、校准和线性系数全部只在拟合行计算。分类采用带固定基线 offset 的正则 Logistic IRLS，MAE 采用平滑绝对误差 IRLS，Spearman 采用 Gaussian-rank 残差 Ridge。

其他 assay 分支仅使用官方 train 的其他任务实测值，最终拟合时扩展为官方 train+valid。目标任务实测值及 mask 不进入辅助特征。目标 assay 的历史预测作为基线输入，这是模型输出而非测试标签。测试结构来自平台模板，未解析 test.csv 或其标签；没有新增外部数据或预训练权重。保留的历史底稿仍包含早期预训练来源。

## 冻结与确认

仅在 fold0/fold1 选择任务、配置、修正强度；冻结 7 个候选后检查 fold2/official valid，未根据确认结果重新调参。3 个任务满足原定四部分增益均为正的条件：

| 任务 | 配置 / 修正强度 | fold0 增益 | fold1 增益 | fold2 增益 | valid 增益 |
| --- | --- | ---: | ---: | ---: | ---: |
| 肝细胞清除率 | assay Ridge α=1 / 1.0 | 0.010613 | 0.007916 | 0.003839 | 0.005863 |
| 微粒体清除率 | assay Ridge α=1 / 0.5 | 0.003339 | 0.004124 | 0.003586 | 0.004011 |
| hERG | physical kernel α=0.3 / 0.25 | 0.003405 | 0.003654 | 0.002263 | 0.000992 |

清除率使用 Spearman，hERG 使用 AUROC。三项 CYP substrate 和半衰期未通过全部确认，不进入提交。CYP3A4 substrate 第三折变化约为 -1.1e-16，数值上相当于持平；原定条件严格要求正值，本轮仍拒绝，没有在看到确认后放宽条件。

最终更新肝细胞清除率 243 行、微粒体清除率 221 行、hERG 132 行，共 **596 行**；其余 19 项保留 v84 原预测字符串。肝细胞清除率完整替换 v84 对应端点为新残差模型预测，不重复应用 v84 邻居专家。候选在开发时从历史原始 proxy 残差化，最终从 v73 原端点残差化，再与 v84 重放基线比较，这并不构成完整 v84 同折 OOF。

## 复核和不确定性

独立进程重载 15 个模型（每项 4 个开发/确认部分和 1 个最终部分），核验精确训练查询行、canonical/scaffold 分离、来源标签、拟合行预处理、目标变换、保存系数与重新拟合系数、核设计 CPU float64 复算、预测批大小一致性和 CSV 预测值。模板的非预测字段及字节、Drug_ID 原始字符串、BOM 和 CRLF 必须保持一致。

每项在 fold2 和 valid 上做 1,500 次配对骨架 bootstrap，仅作报告，不改变冻结选择：

| 任务 / 部分 | 增益 95% 区间 | 正增益比例 |
| --- | --- | ---: |
| 肝细胞 / fold2 | [-0.009953, 0.018298] | 72.13% |
| 肝细胞 / valid | [-0.008783, 0.020449] | 78.53% |
| 微粒体 / fold2 | [-0.002591, 0.010906] | 86.60% |
| 微粒体 / valid | [-0.001097, 0.011928] | 93.93% |
| hERG / fold2 | [-0.003038, 0.010861] | 75.80% |
| hERG / valid | [-0.011131, 0.016408] | 48.60% |

所有区间均跨过零，尤其 hERG 的 valid 收益偏弱，不能宣称统计显著或可保证线上涨分。开发标签长期复用，历史 proxy 不是完整 v84 OOF，辅助 assay 是条件信息，bootstrap 不能消除这些限制。局部指标不可直接换算为官方总分，当前证据不足以承诺达到 52 分。
