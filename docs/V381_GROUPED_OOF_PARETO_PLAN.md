# v381 分组折外中位数与排序专家融合

前四轮完成预算后只有v380脂溶性四区下降0.18%–0.63%，九项平均5%目标未达到。四个Spearman任务仍有MAE/排序冲突。v380实验CSV单独保留、未获官方评分，本轮仍与已知51.271关联的v374比较。

本轮以可重训的三个凸专家建立真正内部OOF：开平方计数多项式核的原单位中位数SVR、旧计数Tanimoto核的原单位中位数SVR，以及开平方核的高斯秩SVR。最后一项通过仅拟合集标签的经验分位数映回原单位。三个专家共享当前允许输入，禁止将旧代理OOF当作新训练输入。

每个外层分区使用三折骨架分组OOF，全部预处理在各内层拟合集重建。非负权重和偏置通过原单位绝对误差线性规划学习，并比较0.01/0.05正则强度。四排序任务另比较0.3/1.0权重的跨骨架成对间隔损失。排序代理目标不保证Spearman提高。

与v372已失败的四专家融合的区别：更换为v380表示及专门的秩专家，引入MAE/排序联合凸目标、覆盖九任务、不使用物性分桶门控。不能称融合本身是首次或创新突破。本轮也没有恢复完整旧模型集成的权重。

开发预算18个外层任务分区×4个内层/全量拟合集×3个SVR，共216次基础拟合。52个开发预测包。每个SVR达到固定1e-5求解容差、最大100万迭代并检查收敛；无随机种子，不能把确定性求解虚称多种子。线性规划保留原始/对偶最优性证书。全部开发完成后仅由fold0/1确定唯一配置及融合权重，随后固定确认fold2/valid，失败无回退。

实验CSV需四区MAE点估计均改善，排序任务还需四区Spearman改善。严格稳定性另外检查实际幅度及成组bootstrap，未满足严格门槛的明确标记实验。查询标签扰动、核重建、全部内层OOF/最终输出重放、线性规划证书和文件哈希需独立进程核验。

本轮所有拟合只在指定25870远端完成。无外部数据、标签或预训练。九项平均相对MAE降幅分母保持9，另报5个直接计分任务，不把未采用研究信号算入部署收益。公开验证已复用，四个排序MAE参考来自历史秩校准，这些局限继续保留。没有官方提分预测或5%保证。
