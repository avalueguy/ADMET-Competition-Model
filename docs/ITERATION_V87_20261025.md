# v87：修正排序损失尺度，确认失败，不生成提交

v85 是用户报告的最高官方版本（50.889）。v86 是未经官方评分的候选，在 v85 上更新 CYP2D6 底物。v87 以 v86 为基线，修复 v86 排序对照的零分裂问题，并重新评估直接排序是否能提供更明显收益。

## 固定方案

v86 的 MAP/Pairwise 各 104 个模型全部零分裂。v87 在查看本轮确认结果之前固定排序参数：`min_child_weight=0.001`、L1=0、L2=1，MAP 使用 top64 配对，Pairwise 使用 mean16 配对。辅助 assay、辅助 assay+理化描述符、辅助 assay+多视图结构三种输入，分别 200/400/400 轮，固定两个种子 874026/874027。修正后模型产生了分裂，验证了先前零收益包含实现配置问题。

对 13 个分类任务的 6 个配置及 3 个融合权重，仅在 legacy fold0/fold1 选择每任务一个配置；两折最小收益超过 0.0005 后冻结。随后检查 fold2、official valid；四部分均正增益才可输出。本轮未因确认结果调参或减小权重以挽救候选。

基线继续重放 v85 已采用的改动，并额外重放 v86 CYP2D6 底物改动。历史 proxy 不是完整 v86 OOF。其他官方 assay 的同分子测量仍为条件信息，目标 assay 值和 mask 不进入输入。无新增外部数据或预训练权重，不解析测试标签。

## 对方向的判断

将分类损失改为排序损失能改变树结构和排序，但在这些小样本任务上没有得到跨部分一致的收益。此前“参数换了却没变化”有确定的正则尺度原因；修正后仍出现开发折改善、确认折下降，说明不能仅靠排序目标解决目前总分瓶颈。

不能把以上结果推广为所有排序模型都无效，也不能承诺 v86 线上改善。后续更值得优先处理的是完整当前版本同折预测与多任务结构表示的可靠验证，减少历史 proxy 误差和长期复用标签造成的选择偏差。当前没有新的独立官方测试分任务反馈，仍无法把某个局部指标换算为官方总分。

保存协议、全部开发结果、冻结选择和确认结果于 `admet_model_outputs_v87/`。另对保存的全部 booster 执行哈希和预测重载检查；该检查范围为模型到缓存预测的一致性，不冒充完整输入来源重建。拒绝分支归档依赖已核验的 `v86_metric_ranking_20261025.tar.gz` 恢复共享数据及历史基线。
