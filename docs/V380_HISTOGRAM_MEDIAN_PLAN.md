# v380：分子片段分布相似度与绝对误差核专家

目标保持9项连续任务相对MAE降幅等权平均至少5%，另报5项官方MAE。拒绝更新计零；四项Spearman任务必须同时改善官方排序。本轮只用官方输入，全部拟合在指定25870远端，未使用外部数据或预训练权重。

现有v102/v150/v233/v371/v374已经比较计数Tanimoto、若干RBF、监督多核和残差路线；v372也已完成嵌套四专家融合但失败。v380不把这些旧方法改名。新的可检验变化是：六个非负片段计数块各自L1归一化并开平方，再比较显式映射点积的多项式核与该映射上的两带宽高斯核。理化/测量上下文保留，以弥补归一化削弱的分子大小信息。

80%新指纹核、15%原增强特征RBF、5%物理RBF。每个任务比较C=3/30，epsilon=0直接绝对残差损失，容差1e-5、最大100万次求解；未收敛视为失败，不把短迭代当结果。四项非负排序任务另比较固定导数补偿的log1p目标，最终按原单位MAE验收；此补偿仅局部近似，不能宣称与原单位风险严格等价。

共104个开发拟合：5项×2分区×4配置，加4项×2分区×8配置。凸求解没有随机种子，不制造重复种子数量。先完成全部开发配置，再由fold0/1固定唯一模型与权重(.1/.25/.5/.75/1)，再确认fold2/valid；失败不换配方。没有基于短期验证的提前终止。

排序任务用同一原单位融合预测计算MAE、Spearman和写CSV。四区MAE和对应排序均正向才交实验CSV；严格采用另需1.2%实际幅度及成组bootstrap支持。独立重放、查询标签扰动、核块重建/PSD检查、输入源码哈希和提交模板检查在交付前完成。

这轮不是Transformer的永久替代，而是补足相似度方向的对照。完整历史OOF仍缺失，旧基线部分为proxy，四排序MAE参考来自拟合标签分位数校准，公开验证长期复用，所有局部结果都不能预言官方分数。未测到5%就不称达标。
