## 官方计分与改进重点

使用可见的 67 份官方成绩单，核对 1,474 个任务结果，以下关系在分数六位小数的舍入误差内全部成立。它们是经验对账结果，不冒充官网公布的规范。

- AUROC、AUPRC：`100 × raw / (raw + reference)`。
- MAE：`100 × reference / (raw + reference)`。
- Spearman：`100 × (raw + 1) / (raw + reference + 2)`。
- 总分：22 项归一化分数的平均值。

从 v145 到 52，累计需要约 18.345 个分项分数的增益。HIA AUROC 已为 1，无提升空间，虽然其归一化分数约为 50.14。

若五个 MAE 任务的误差都降低 10%，公式对应总分约 +0.596；四个 Spearman 任务若都提高 0.1，对应约 +0.267。这是固定情景下的算术敏感性，不是新模型的成绩预测，也不能说明这些改善能实际实现。完整复核见 `v184_official_objective_audit.json`。
