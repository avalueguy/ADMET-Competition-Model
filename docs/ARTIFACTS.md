# Release 附件

附件位于私有仓库的 `handoff-2026-10-20` Release，只有仓库授权者可以下载。官方数据和模型仅用于本次授权交接，请勿转为公开仓库。

| 文件 | 大小（十进制） | 用途 |
| --- | ---: | --- |
| runtime-inputs.tar.gz | 344,250,076 字节 | 官方训练/验证/测试及模板、历史实际提交、v23/v24 特征、分子图缓存、公共预训练模型 |
| graph-sources.tar.gz | 388,224,163 字节 | v27 源图网络及 v43 相关特征，支持图核和图表征复现 |
| latest-models-v61-v65.tar.gz | 719,547,346 字节 | v60-v65 当前产物；最新权重、条件化模型、CV/valid/test 预测与拟合预处理器；含 v60 代理重建所需选中源预测 |
| exact-remote-source-and-metadata.tar.gz | 6,763,413 字节 | 精确远程源码及所有历史轻量 JSON，保证递归签名所需文件存在 |
| fold-state.tar.gz | 27,404 字节 | 三折全局骨架划分的原始行索引，保证验证切分一致 |

每个包对应一个 `*.manifest.json`，逐文件记录相对路径、字节数、SHA256。总包校验见 `artifact_manifest.json` 和 `SHA256SUMS`。

没有打包 Python `.venv`、SSH/网站/GitHub 凭据、未选入当前模型的历史训练权重，也没有把已作废的自适应推理缓存作为活动模型。保持 v60 的实际 CSV 和已保存代理预测，不需要重新加载所有旧模型就可以继续本轮实验。

因此，此交接可以恢复本轮 v61/v62/v63/v65 的模型与比赛批次结果，但**不等于任意新分子的所有历史集成成员都已具备完整推理权重**。如果未来需要产品化通用推理，需要重新实现和固化一套独立可部署基线。
