# v73：以 v72 为底稿的候选

用户报告 v72 官方得分为 50.628，第十名为 51.7，差距 1.072。v72 保留为已知最好版本和回退文件。v73 尚无官方分数，不能据本地验证推算平台得分或承诺进入前十。

本轮在已授权 AutoDL A100 40GB 上完成 12 个任务的两类结构专家（96 个开发模型），并以 CPU 完成 11 个任务的结构控制/其他公开测量条件专家（88 个开发模型）。最终为选中的 5 个端点各拟合两个随机种子，共 10 个最终模型。新专家只使用官方 train/valid 标签和官方 SMILES，不解析 test Y，不使用外部标签或预训练权重。底稿 v72/v56 继承历史预训练来源，不能把整个候选称为无预训练。

结构专家加入 chiral Morgan3、RDKit path、atom-pair、最大含碳片段 Morgan 指纹，以及全分子/parent 理化性质。理化残差专家也已训练，但最终未采用。CYP2D6 底物条件专家使用同 canonical 分子的其他官方任务公开测量；目标任务的值和缺失 mask 均不进入特征。开发阶段辅助标签限官方 train；最终阶段为官方 train+valid。这属于有其他测量时的条件化预测，不是纯结构的全局未知骨架评估。
