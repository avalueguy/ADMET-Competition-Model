# v80：CYP2C9 基线残差修正

本轮交付 v80 新候选，官方得分尚未知。用户报告的最高成绩仍是 v73 的 50.640，第十名最近为 52.2。v80 只替换 CYP2C9 Veith 的 2,419 条模型预测，其余 21 任务保留原预测字符串。不能把下面的单任务 AUPRC 增益换算为官方总分，不能保证进入前十。

## 方法和选择依据

此前的重复专家叠加、开发与最终树数不一致、历史代理与新分折混用，均不能支撑提分判断。本轮先恢复精确 v24 原分折，再比较回归残差、六视角核 KRR/SVR、分类 GLM 和分类树残差。回归和核分支没有通过全部部分的正收益要求，不进入提交。开发记录和失败日志保留，未把失败实验包装成提交版本。

新方法把 CYP2C9 原预测转换为分位数 logit，以只在拟合行拟合的正斜率 Logistic 校准作为固定 offset。小型 CatBoost 学习其分类误差，特征只有其他 21 个官方任务的实测值、缺失 mask 和基线 rank logit。CYP2C9 目标值与目标 mask 均不进入辅助特征。固定 300 棵、深度 4、学习率 0.025、L2=50、种子 802026/802027/802028，平均残差 raw score 后加 offset，再取 sigmoid。

开发与嵌套检查只使用其他任务 train 标签；最终模型使用官方 train+valid。结构/身份产物来自已存在、按哈希校验的化学缓存，没有修改 RDKit 版本信息或重新生成不同版本特征。测试结构只从上传模板读取，未打开 test.csv、未使用测试目标标签或新增外部数据。
