# v379：小容量、分位数与排序联合目标

目标仍为9项连续任务相对MAE降幅等权平均至少5%，同时单独考核5项官方MAE。没有通过更新检查的任务计零，不把获胜子集的平均冒称总体改善。官方已知最好仍为51.271。

这是在完整v377/v378学习曲线之后固定的新比较。v378原始模型和失败结果保留；本轮不修改它们，也不在确认区上重新选择v378参数。

## 机制与消融

两条路线共享6个2048维指纹token和一个数值上下文token、单层32维4头Transformer，较v378减少层数和宽度。dropout为0.3、AdamW权重衰减0.1；前1000步直接同步参数，之后以0.995衰减作参数指数平均。两条路线使用完全一致的预算和参数平均方式，比较分位数辅助目标的作用；没有单独消融容量、dropout和EMA各自的贡献。

- `small_ema_l1`：原单位标签经拟合集仿射缩放的中位数绝对误差。
- `small_ema_quantiles`：中位数加0.2/0.8分位数辅助损失，三个输出通过softplus保证次序；最终预测只取中位数。辅助区间没有校准覆盖率保证。
- 四项Spearman任务在上述目标上加入固定0.3权重的成对排序损失，标签差小于0.1个拟合集IQR的样本对跳过。单独检查真实MAE与官方Spearman；不能以MAE替代排序分数。

选择更小模型的依据是：v378的18个任务/方法组合中，只有3个在最长档相对最短档同时改善两个开发区。这个描述只用于设计下一轮，不能证明小模型必然更好。v377的27个组合中16个随预算增加同步改善，因此树的长预算结果也完整保留，不能据神经曲线否定树方法。

## 完整预算与验收

全部9项、两种方法、两个开发分区、两个种子3791105/3791106。每个种子完整训练6000步，保存1000/3000/6000；共36条开发曲线、72个完整种子训练、108个开发预测包。6个独立进程只在指定25870远端运行。先通过小规模真实GPU拟合和保存重放检查，再启动正式训练。

不根据1000步结果提前中止。全部开发曲线完成后，fold0/1以最小相对降幅最大为目标选唯一配置和融合权重。四项排序任务还要求两个开发区排序增益为正。选型冻结后再检查fold2/valid，失败不换配方。

四分区MAE均下降，且排序任务四分区Spearman均提升，才生成明确标注的实验CSV。严格采用另需实际幅度和分组bootstrap支持。独立重放预测、查询标签扰动、冻结输入/源码/模型哈希，模板逐行核验均在交付前完成。

v379的排序任务使用同一份原单位线性融合预测计算MAE、Spearman并写入CSV，避免把一份原单位输出的MAE收益归到另一份秩融合输出。此项在任何v379拟合前修订，原始预发布源码和归档保留于`prelaunch_source_v1`，修订回执为`source_amendment.json`。v377/v378保持原协议。

## 数据和解释限制

只使用已核验官方数据及其结构特征，全部模型拟合仅指定远端。不下载外部预训练权重或标签。最终融合对照精确v374关联文件，官方51.271来自用户反馈，平台未给上传字节哈希。

四个排序任务的MAE对照是拟合集标签分位数校准后的历史预测秩，不能称为恢复了旧模型原单位误差。完整历史集成OOF仍部分为代理，公开标签已经长期复用；任何局部降幅都不能等同隐藏测试降幅。

长期路线仍保留：恢复历史完整集成的真实分组OOF；针对可观测测量条件做任务专家；只在完成曲线支持时增加预算。上一轮失败不是永久否定Transformer，但也不是继续同一配置就会达到5%的证据。

本轮追加检查了18份早期及关键方法文件，并建立97份本地源码声明索引，见`v379_focused_material_review.json`与`v379_expanded_local_method_index.json`。索引条目不是97个独立完成的算法。另读参数平均与条件分位数的3份原始来源，见`v379_primary_references.json`；不把图像分类的EMA收益或随机森林分位数结论当成本赛的5%效果证据。

当前服务器的只读历史可用性盘点显示：v23/v44输出目录缺失，v46/v52/v56仅余结果文件，v67有部分预测但无完整权重；见实验目录`history_availability.json`。此结论只覆盖已盘点路径，不能断言其他旧备份不存在。完整历史OOF无法仅靠现有目录直接重放，后续应建立可完整重训的新基线，不能声称已恢复旧集成。
